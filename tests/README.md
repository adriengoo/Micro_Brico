# Campagnes de test pilotées par agents

Ce dossier contient les livrables d'une campagne de test, séparés du code de l'application.

Une campagne suit cet ordre :

1. stratégie de test ;
2. fiches de test ;
3. revue des fiches ;
4. exécution et collecte des résultats ;
5. synthèse.

L'orchestrateur ne démarre jamais une étape tant que l'étape précédente n'a pas été validée par le responsable de campagne. Les fichiers de contrat décrivent les entrées et sorties attendues.
